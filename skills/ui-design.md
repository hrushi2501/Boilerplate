# Skill: UI Design Conventions

## When to Use

Use when creating, refining, or styling user interfaces, design systems, layouts, or interactive components.

## Important Conventions

- **Philosophy**: Clean, modern, professional, fast, responsive, accessible, minimal animation.
- **21st.dev Conventions**: Use sleek, production-grade component patterns with high visual Polish, clean borders, and crisp typography.
- **Emil Design & Ponytail Conventions**: High contrast, subtle borders (`border-border`), consistent spacing scales (`gap-2`, `gap-4`, `gap-6`), and intentional typography hierarchy.
- **React Bits Usage**: Apply React Bits **selectively**. Animations should only be added when they measurably enhance user feedback or state transition clarity.
- **Color Discipline**: Rely on theme tokens (`bg-background`, `bg-card`, `text-foreground`, `text-muted-foreground`, `border-border`). Avoid garish or uncurated primary colors.

## Things to Avoid

- Do NOT make everything animated; gratuitous motion detracts from hackathon product usability.
- Do NOT build flashy, distracting landing pages with fake product claims.
- Do NOT create low-contrast text or illegible backgrounds.
- Do NOT introduce bulky animation libraries when CSS transitions or Tailwind utility animations suffice.
